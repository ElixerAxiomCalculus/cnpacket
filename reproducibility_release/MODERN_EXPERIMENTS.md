# ECU-MALNETT V2 supplementary experiments and alignment review

This addition packages existing ECU-MALNETT V2 results and the completed 25-record alignment review. It does not alter the original manuscript title, earlier results, scientific code, data or experiments. Packaging date: 7 November 2026 (Asia/Calcutta). No experiment, preprocessing, audit extraction, model training or dependency installation was executed for this packaging update.

## Dataset and scientific scope

The five source groups are APT28, APT29, Lazarus, RustyStealer and Turla. The existing extraction covers 53 captures and retains 881 bidirectional flows after its filtering/deduplication. These are Construct-positive source-group labels, not independently verified malicious flows or conclusive attribution to those groups.

Dataset attribution: Matthew G. Gaber, Mohiuddin Ahmed and Michael N. Johnstone, *ECU-MALNETT V2*, Edith Cowan University, 2026. Obtain the APT subset through the [official dataset record](https://ro.ecu.edu.au/datasets/164/) ([dataset DOI](https://doi.org/10.25958/t81p-ap36)). The provider describes automatically inferred Construct labels and lists CC BY-NC 4.0 terms; consult that record for dataset access and attribution. No provider PCAP, Construct session CSV, payload, model-ready sequence or cached feature array is redistributed here. Project-code licensing remains unresolved, as described in README.

The neural experiment uses one frozen capture split, five closed-set training seeds, and five target-group open-set rotations. Each rotation excludes one target and a separate calibration group, leaving three known groups; open-set training uses the first configured seed. Fifty-packet and five-packet evaluations use the same trained model/normalization and held-out flows. The `original_50_packet` and `recalibrated_5_packet` rows are separate threshold policies. Few-shot adaptation uses K=1/5/10 nested supports from target training captures and queries from target test captures; the resulting task has four classes, distinct from the earlier USTC nine-family task.

The follow-up compares fixed Random Forest and logistic regression hyperparameters across five capture-split seeds. It extracts 116 features: 50 signed/log-size positions, 50 log-IAT positions, and 16 summary features. Logistic scaling is fit inside the training pipeline. Training at 50 and testing at five packets is distinct from training/testing at five packets. The validation subset is retained but unused for tuning. Repeated capture partitions are not independent dataset replications. Do not merge these results with the original three-dataset populations or the deployed USTC checkpoint.

## What the alignment review establishes

The existing audit checked 25 sampled flows against 24 original PCAPs and 27 directional Construct rows, covering 349 packets: **25 checked, 0 unresolved, 0 mismatched**. The independent header decoder and TShark agreed on endpoints, ports, transport, counts and timestamps. Construct timestamps matched the final directional packet's stored PCAP time, while session duration matched last minus first within one microsecond. The copied directional table retains the residuals and frame references.

`checked` means CSV-to-PCAP alignment only. This was assistant tool-assisted review, not external human sign-off. The existing baseline summary field `human_rows_checked_for_alignment` is preserved exactly as generated by its source script; it counts checked CSV rows and must not be read as proof of an external human review. Likewise, `labels_are_independently_verified` remains false. Baseline completion does not establish malicious ground truth.

The original pending review CSV remains under `apt_v2_followup_20261107/`. The independently verified copy is under `manual_audit/`, and the actual completed baseline run contains that same verified content at `apt_v2_followup_20261107_reviewed/label_review_samples.csv`. Their different statuses are intentional evidence of the workflow. No pending statuses were silently changed in an original file.

## Reproduce in an independent execution workspace

Use the ML environment and requirements described in README. The two modern experiment scripts import the same NumPy, torch, scikit-learn, SciPy and matplotlib dependencies already in the included ML lock; TShark is required for external PCAP extraction. The verification script uses Python standard-library modules plus the TShark executable and Git CLI. It does not require a new Python dependency.

Run all commands below only from an independently obtained, writable execution copy of the release. Its current directory and script-derived root must both be that release root. Keep the packaged evidence unchanged; select fresh run names. These are future reproduction commands, not commands executed for this update.

Obtain `APT.zip` from the provider and arrange the original contents as:

```text
data/raw/APT/
├── pcaps/{APT28,APT29,Lazarus,RustyStealer,Turla}/...pcap
└── analysis_output_{apt28,apt29,lazarus,rustystealer,turla}_baseline_labelled/..._sessions.csv
```

Do not copy the machine-specific original `provenance.json` into a new run. The original recorded full-run settings were CUDA, 60 closed epochs, 40 open epochs, CE batch 512, SupCon batch 256, and seeds 20261011–20261015; these are also retained in `summary.json`. The scripts must run unchanged so their extraction rules, seeds, splits, normalizations and source-hash gates remain intact.

### Reconstruct the audited sequence cache

The package omits `cached_flow_sequences.npz`, even though it is small, because it is a binary processed sequence dataset. Original input snapshots and audit-summary provenance are also excluded; a fresh audit generates them locally. Therefore the packaged reviewed baseline directory cannot be run directly. Create a fresh audit directory and regenerate a cache from official inputs:

```bash
python3 scripts/modern_validation/ecu_malnett_followup.py \
  --mode audit \
  --dataset-root "$PWD/data/raw/APT" \
  --run-name apt_v2_followup_reproduction \
  --previous-run-name apt_v2_full_20261106
```

This extracts data, reconstructs/checks the included frozen manifest and writes a new audit/cache/snapshot with blank review statuses. It is intentionally not run during packaging. The new directory must not already exist. If the provider files or extraction environment differ, the frozen-manifest check may fail; do not edit the manifest/hash gates to hide that difference.

After independently confirming that these are the same raw inputs and sample records as the reviewed originals, this command verifies all non-review fields before transferring the packaged checked CSV into the **new execution audit directory**. It replaces only the new audit's blank review CSV. Do not use this transfer to attest to different raw data or to satisfy an external human-sign-off requirement.

```bash
python3 - <<'PY'
import csv
import shutil
from pathlib import Path
base = Path('artifacts/modern_validation/ecu_malnett_v2')
source = base / 'manual_audit/label_review_samples_verified.csv'
target = base / 'apt_v2_followup_reproduction/label_review_samples.csv'
def read(path):
    with path.open(newline='', encoding='utf-8-sig') as handle:
        return list(csv.DictReader(handle))
checked, fresh = read(source), read(target)
assert len(checked) == len(fresh) == 25
for old, new in zip(checked, fresh):
    assert old['review_status'] == 'checked'
    assert {k: v for k, v in old.items() if k not in {'review_status', 'review_notes'}} == {
        k: v for k, v in new.items() if k not in {'review_status', 'review_notes'}}
shutil.copyfile(source, target)
PY
```

Run the baselines against that new reviewed audit/cache:

```bash
python3 scripts/modern_validation/ecu_malnett_followup.py \
  --mode baselines \
  --dataset-root "$PWD/data/raw/APT" \
  --run-name apt_v2_followup_reproduction \
  --previous-run-name apt_v2_full_20261106 \
  --split-seeds 20261011 20261012 20261013 20261014 20261015
```

This trains models and writes aggregate results, per-flow predictions and split memberships only into the new run. Reusing a directory with completed baseline outputs is refused. The script reads `label_review_samples.csv` from its selected run directory, not from `manual_audit/`; this is the cause of the previously diagnosed blank-status error. Raw-input snapshot checks compare sizes/mtimes and are environment-sensitive; generating a fresh audit records the local provider inputs without weakening the original checks.

### Recreate the original neural workflow

This separate command creates a new neural experiment run, writes manifests/results/figures, and uses the original recorded settings:

```bash
python3 scripts/modern_validation/ecu_malnett_apt_validation.py \
  --mode run \
  --dataset-root "$PWD/data/raw/APT" \
  --output-root "$PWD/artifacts/modern_validation/ecu_malnett_v2" \
  --run-name apt_neural_reproduction \
  --closed-epochs 60 --open-epochs 40 \
  --batch-size 512 --supcon-batch-size 256 --device cuda \
  --seeds 20261011 20261012 20261013 20261014 20261015
```

The original runner trains/evaluates models in memory and does not save those neural weights. Its five-packet scores are produced during that run. Recreating the evidence requires retraining, not pretending that a frozen checkpoint is included. CUDA availability and deterministic numerical reproduction are not established by packaging checks.
